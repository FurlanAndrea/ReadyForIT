SAP Document AI
Base Edition vs. Premium Edition vs. Embedded Edition
What's included in each service plan — and when to upgrade
Base Edition
Document AI
Base Edition
Entry-level plan for standard document extraction using pre-built ML models. Basic UI & REST APIs only.
  • Basic UI & REST APIs
  • Pre-built document types (invoice, PO, etc.)
  • No Workspace or OData V4 APIs
  • No generative AI extraction
  • Metered in blocks of 100 documents
Best for: Simple, standard document processing
Premium Edition
Document AI
Premium Edition
Full access to all features including Workspace, OData V4 APIs, generative AI, and advanced capabilities.
  • Basic UI & REST APIs
  • Workspace & OData V4 APIs
  • Generative AI extraction
  • Channels, Workflows & Transports
  • Metered in blocks of 100 docs, requests & users
Best for: Full-featured standalone deployments
Embedded Edition ✦
Document AI
Embedded Edition
Same full feature set as Premium Edition but designed for integration into SAP solutions. Charged in AI units.
  • All Premium Edition features
  • Designed for SAP solution integration
  • Channels, Workflows & Transports
  • Instant Learning support
  • Metered in requests & users (AI units)
Best for: Embedding into SAP applications

Licensing & Service Plans (SAP BTP)
Base Edition
Plan: blocks_of_100
  • Enterprise & Trial accounts
  • Metered per 100 documents & compute hours
  • Max 10,000 docs/hour per tenant
  • Up to 100 pages per document
  • Can upgrade to Premium or Embedded
Premium Edition
Plan: premium_edition
  • Enterprise accounts only
  • Metered in blocks of 100 docs, requests & users
  • Max 10,000 docs/hour per tenant
  • Up to 100 pages per document
  • Can upgrade to Embedded Edition
Embedded Edition
Plan: embedded_edition
  • Enterprise accounts only
  • Metered in requests & users (AI units)
  • Max 10,000 docs/hour per tenant
  • Up to 100 pages per document
  • Also available: Free plan for dev/trial (50 pages/30 days)
